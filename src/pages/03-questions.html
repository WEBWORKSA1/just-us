Getting more out of a question

  • Match the deck to the moment. Fun for the car, deep for a quiet evening, ten-minute for a busy week.
  • Phones face down. Read the card, then put the device aside while you talk.
  • Skip freely. If a question does not suit tonight, pass. It will still be there next month.
  • Make it a habit. The daily question picks one for you, every day.
